# 厚外成长智慧学习与手册内容说明 V0.1

编制日期：2026年11月5日。适用对象：初高中任课教师、班主任、学生、家庭及工程接手人员。

本轮把智慧作业反馈接到学生个人手册，再由厚外成长保留后续变化。教师能够从具体作答判断下一节课讲什么、哪些学生需要怎样的帮助；学生知道自己已懂什么、卡在哪里、下一步可以做什么；家庭看到学校采取的行动和随后发生的变化。

**当前交付是初版内容与合成数据演示。** 原题引用现有初高中 Demo 的数学记录，新增题目用于演示隔一段时间再看能否独立运用。界面、样张和数据约定不表示讯飞、考试系统或正式小程序已经联调，也不代表学生已实际完成任务、教师已实际确认或教学效果已经提升。

## 一 每周只抓一到两个重点

围绕学校已有作业、课堂任务和考试开展短回看，每位学生每周保留一到两个值得继续弄清的问题。任务量根据当前课程和学生情况调整，不新增统一考试，不要求逐题计时或长篇日更，也不把错题重新抄写作为完成标志。

初中侧重任务拆解、概念理解、订正方法、习惯和时间安排。高中进一步要求学生说明条件与推理，比较方法的适用范围，逐步自主安排学科投入。两学段共用流程，按本次作答及后续变化安排支持，不给学生固定的层次标签。

## 二 教学工作怎样接到学生行动

| 环节 | 教师与学生要做什么 | 应留下的内容 |
|---|---|---|
| 设 | 教师从既有任务确定本周一到两个目标，查看各科安排 | 目标、任务预计用时、完成时间、复看时间 |
| 批 | 读取原题、原答和原始反馈，教师核对值得进一步了解的线索 | 来源编号、时间、学科知识点、教师确认与说明 |
| 订 | 学生解释原来怎样想、怎样修改，选择是否申请家庭分享 | 订正文本、提交状态、分享选择、教师回应 |
| 评 | 教师判断需要全班讲什么、怎样组织解释与方法比较 | 讲评主题、方法、课堂观察与已保存状态 |
| 辅 | 对仍需帮助的学生安排面批、针对练习或策略面谈 | 行动、负责人、复看日期，与原支持事项关联 |
| 再看 | 学生完成不同情境的任务，教师复核能否独立运用 | 再练作答与理由、教师判断、下一步反馈 |

原始反馈先标为“待确认线索”。教师要结合原题和学生解释核对，避免将系统给出的错因直接当作定论。学生提交订正后，教师可以给出回应；**已经订正与能够独立运用分别记录**，需要后续任务的具体表现来判断。

老师讲评之后仍可调整方法。一次再练仍需帮助时，保留具体困难并继续支持；能够独立完成时，也应说明是在什么题目和条件下观察到的，不把单次表现写成稳定能力或教学方法的因果效果。

## 三 初中完整案例

### 从起始量与变化率的混淆开始

合成学生林予安，香江路校区八年级2班。原题引用现有记录 j1-h2，来源编号 J1-H2，日期2026年10月26日，来源为讯飞智慧作业模拟记录，知识点为一次函数图像与情境。

原题是某水箱开始有水20升，每分钟均匀注水3升，写出水箱内水量y与时间x的关系式，并解释图像与纵轴交点。原答写成“y=3x；交点表示每分钟注水3升”。“尚未区分起始量与变化率”作为原始反馈线索，先由教师结合学生解释确认。

本周目标是区分开始有多少与每次增加多少，并能用关系式和图像解释新情境。教师面批时先请学生在图上标出开始时的20升，再说明每分钟增加3升。订正说明应写清y=3x+20，交点(0,20)表示开始时已有20升水，不能只把最终答案改对。

### 把解释接到讲评与支持

讲评可以比较“开始为0”与“开始不为0”两个情境，请学生先标图像起点，再解释变化率。对仍混淆的学生，教师安排一次情境卡面批，并约定复看日期；支持事项由既有成长支持功能保存，手册引用同一事项，不另建一份学生事实。

新再练题改为研学器材租用：固定服务费12元，每小时6元，设使用x小时，总费用为y元，写出关系式并解释纵轴交点。预计10分钟，属于教学安排示例。教师核对时看学生是否独立写出y=6x+12，并说明(0,12)表示固定服务费12元、6表示每小时费用，实际情境取x≥0。

学生可在纸上完成关系式、图像和理由，再选择回填关键解释。教师根据实际作答选择“能够独立运用”或“仍需支持”，并记录具体表现。样张预留再练位置，不预填已经改善的结果。家庭版本可以提示家长听孩子解释一次固定费用与按小时费用，不额外增加同类题。

## 四 高中完整案例

### 先检查条件再选择解题路径

合成学生陈书言，兴国路校区高二3班。原题引用记录 s1-h2，来源编号 S1-H2，日期2026年10月26日，来源为讯飞智慧作业模拟记录，知识点为导数与函数单调性。

原题为f(x)=x³−3ax，按参数a讨论单调区间并解释分类依据。原答直接由f′(x)=0得到x=±√a，再列符号表，没有先判断a是否大于0。教师核对的重点是参数条件与驻点存在性的关系，而不是仅判断计算步骤是否写完。

学生订正时先写f′(x)=3(x²−a)。a≤0时导数非负，函数在R上单调递增；a=0时导数在孤立点为0，不因此改变单调性。a>0时，再以−√a、√a划分区间，判断增减变化。学生还要比较符号表法和图像法怎样帮助检查条件。

### 用不同结构的题目再看一次

讲评增加条件检查与两条方法的比较。个别支持通过一次策略面谈，请学生解释为何按该条件分类，再由自己选择核对方法。学生能够讲出适用条件之后，仍需在不同题目上再看是否会主动检查。

新再练题为g(x)=x³−3x²+kx，按参数k讨论单调区间，并说明为何先判断k与3的大小。预计12分钟，属于教学安排示例。教师核对依据为g′(x)=3(x−1)²+k−3：k≥3时在R上递增；k<3时令u=1−√(1−k/3)、v=1+√(1−k/3)，函数在(−∞,u)及(v,+∞)递增，在(u,v)递减。k=3时导数只在x=1为0，仍在R上递增。

教师复看时同时关注答案、条件说明和方法选择的理由。需要提示才能完成的情况如实记录，不把“完成一道题”自动换成掌握。家庭可倾听一次方法比较，帮助留出自主安排和休息时间；学科投入的调整仍由学生与老师结合近期情况商量。

## 五 手册保留七个栏目

| 栏目 | 应呈现的内容 |
|---|---|
| 这周准备学会什么 | 一到两个重点，以及全科任务的整体安排 |
| 我已经有哪些进步 | 已确认的具体表现、作品修改或方法变化 |
| 值得再弄清的问题 | 题目来源、原答及教师确认后的学习问题 |
| 我的订正与解释 | 已提交的任务解释及教师回应，标清分享选择 |
| 下一次准备怎样尝试 | 下一项行动、不同情境的再练及求助方式 |
| 学习以外的成长 | 六好相关经历、贡献、反馈和待继续观察之处 |
| 老师和家庭怎样支持 | 学校已安排的行动、家庭可以配合的一小步 |

手册主单便于快速找到下一步。必要原题和再练题可附页，保留纸笔空间；纸上完成后只回填对判断有用的解释和结果，不要求把整页重抄进小程序。学生拿到纸张或打开程序，都应能直接开始，并知道卡住后向谁求助。

全科总览采用既有教学任务，列出学科、任务、预计用时和完成时间。班主任可以查看和调整全科安排，数学科任只处理数学任务；学生与老师据此减少重复练习，为运动和休息留出时间。**预计用时是安排参考，不是实际测得的耗时。** 首轮不做逐题计时，也不将时间长短用于给学生排名。

## 六 成长记录保持完整与克制

六好固定为品德好、学习好、身心好、气质好、劳动好、特长好。手册只引用既有本人已确认的成长记录，展示实际经历、承担的任务和反馈；记录不足明确写“本期记录还不多”。不按照片上传量、评价次数或作品数量自动形成成长分数。

初中样张引用已确认的学习解释变化与校园劳动记录；高中样张引用已确认的方法修订与社区调查记录。待确认的个人尝试不混入已确认部分。作品展示、运动、劳动与社会实践应与学习安排共同被看见，避免手册变成只记录成绩的文件。

小学已形成的班务屏、照片关联、课堂具体表现、六好分类和教师确认流程可以作为界面与流程来源。初高中减少装饰与公开奖励式包装，将学生解释、方法选择和下一步行动放在主要位置；真实识别、媒体存储与发布权限仍按正式工程核对。

## 七 谁能看见哪些内容

| 角色或状态 | 可见范围与处理方式 |
|---|---|
| 学生本人 | 查看本人的行动单，填写订正和再练；额外私人复盘仍在原复盘功能中 |
| 任课教师 | 在任教范围内处理本学科任务，只读取学生已提交的订正和再练 |
| 班主任 | 整合授权班级的全科安排与必要支持，不扩大专业资料权限 |
| 家庭 | 只读取教师发布的安全快照；学生未选择家庭分享的解释文本不进入家庭版 |
| 课堂与集团 | 课堂仅展示目标或汇总，不显示个人作答；集团仅看授权范围内的进度与支持汇总 |
| 专业老师 | 本学习手册不开放专业入口；心理量表、咨询与原始专业资料不进入手册 |

来源确认、学生提交、教师复核和家庭发布分别显示。教师修改计划后形成新的草稿，家庭继续查看上一发布版本，直到教师再次发布。每份打印稿标明周期、生成时间、版本和适用角色；学生私人草稿不自动打印、不自动分享，任务提交也不等于公开私人复盘。

两份样张采用“合成教师确认示例”，演示来源已确认、订正已提交并复核且申请家庭分享、家庭版本1已发布、新再练待完成。该状态只用于说明成稿形式，不修改 Demo 的初始未确认状态，也不伪称真实教师已经确认。

## 八 老师耗时怎样记录

首轮比较从原始反馈到讲评、支持和周回看的完整工作时间。导入、复核、沟通和纸笔回填整理都应计入，不能只记录系统生成草稿的几秒钟。以下为空白观察表，待参与教师填写，不预填节省时间或效果比例。

| 工作内容 | 原有做法分钟 | 本轮做法分钟 | 次数与情况说明 |
|---|---|---|---|
| 资料导入 | 待记录 | 待记录 | 待记录 |
| 资料复核 | 待记录 | 待记录 | 待记录 |
| 讲评准备 | 待记录 | 待记录 | 待记录 |
| 个别支持 | 待记录 | 待记录 | 待记录 |
| 家校沟通 | 待记录 | 待记录 | 待记录 |
| 纸笔回填 | 待记录 | 待记录 | 待记录 |
| 全部工作合计 | 待记录 | 待记录 | 待记录 |

资料复核包含原题、错因线索、订正与再练的检查；讲评准备包含必要的周回看与反馈整理；个别支持包含面批或策略面谈。课堂教学等额外纳入的工作，应在两种做法中使用同一口径并在说明栏写清楚。

应在相近班级、任务范围和观察周期下记录，注明异常或额外工作。先观察重复整理是否减少、学生是否能开始行动、后续任务是否出现理解与方法变化，再判断总时间有没有下降。当前没有实际耗时和试点成效数据，不作已节时或已提分的结论。

## 九 数据与工程交接

每项任务至少关联学生、学科知识点、来源与时间、原答、教师反馈、行动及后续结果。原题按记录编号引用原有成长档案，不复制出第二份事实库；新增支持调用既有支持功能并保留关联。AI本轮只作为整理与起草的演示概念，未接入真实模型，教师核对后才成为反馈内容。

数字手册和纸质打印使用同一份可打印内容。正式工程需要继续核实学籍与任教关系、源系统真实字段、服务端权限、版本保存、持久化及接口失败处理。演示中的角色切换、本地存储和模拟数据适配不代替正式鉴权或真实接口联调。

## 十 首版怎样判断可用

用初中、高中两个完整案例分别走完确定目标、确认来源、学生订正、教师讲评、支持安排和不同题目再看。核对教师未确认的内容不会变成家庭已发布内容，未分享的解释与私人草稿不会进入家庭样张。

请教师从原始反馈进入讲评和支持，观察是否减少重复整理；请学生实际拿到手册开始一次行动，记录找不到入口或不知道怎样求助的地方；再用后续学校任务观察理解与方法变化。将全科安排、学生休息空间与完整教师耗时一起查看，形成下一轮取舍。样张、界面和测试记录各自说明完成范围，不将合成演示写成实际落地。
