# 厚外成长 · 初高中版

智慧作业与个性化学习手册 V0.1。让教师看清需要讲什么、怎样支持，让学生知道自己懂了什么、下一步怎样学，让家庭读懂学校的行动与后续变化。

**[打开在线 Demo](https://xiaoxiao430.github.io/hw/)** · [内容说明](docs/内容说明.pdf) · [初中手册样张](docs/初中学习手册.pdf) · [高中手册样张](docs/高中学习手册.pdf)

这是公开的产品演示版本，网页与源码均可直接查看。页面内全部使用合成资料，角色切换用于体验流程；没有接入真实学生、作业、考试、心理、AI或通知系统。

## 先这样体验

1. 教师端进入“教学流程”，设定本周一至两个目标，核对原题与作答。
2. 学生端打开“学习手册”，保存草稿或提交订正解释，单独选择是否向家庭分享；卡住时可以明确求助。
3. 教师阅读解释、安排讲评与具体支持；学生完成一道不同情境的新题。
4. 教师在“再看”记录独立运用或仍需支持，修改并发布家庭版。
5. 家长端阅读已发布版本。教师继续改稿时，家长保留上一发布版。

初中案例关注一次函数的起始量与变化率；高中案例关注导数分类讨论的条件与方法选择。订正完成与后续独立运用分别记录，不按上传或评价次数给成长打分。

## 包含哪些内容

- 六种角色：教师、学生、家长、课堂、集团、专业老师；初高中共用底座。
- 教师六步流程：设、批、订、评、辅、再看。
- 同源个人手册、纸笔回填、A4打印、实际求助与带版本的家庭发布。
- 原有成长记录、六好、作品、课堂两轮作答、家校反馈、专业协作与教研案例。
- 班主任全科任务协调；教师按班、按周期填写六环节完整耗时，集团汇总去重。
- 同一浏览器下刷新恢复、跨标签页同步与一键重置；每个人打开时使用自己的本地演示状态。

## 本地运行

需要 Python 3，无需安装第三方依赖。在本目录运行：

```bash
python3 启动.py
```

macOS也可以双击“本地启动.command”。服务仅绑定本机；网页与字体都随包提供，可断网体验。不要只单独保存index.html，请保留完整目录。

启动前检查：

```bash
python3 启动.py --check
```
